# Release scope

The public package contains original research code, the original LoRA adapter, the authorized
14-day forecasting example, SimBench-derived network inputs, and aggregate manuscript tables.
The full market data and complete experimental record bundle are supplied separately under
provider access conditions. Local generated outputs, Python caches, and internal audit runs
are excluded from the archive. The release repository is https://github.com/BambooSeeker/tempr-storage-flexibility.

The corrected comparator results are part of the existing forecast benchmark. The manuscript
retains its original experimental design and its four forecasting configurations.
